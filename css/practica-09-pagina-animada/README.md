# Práctica 9: Página Animada

## Objetivo
Aplicar animaciones, transiciones y transformaciones para crear una página web visualmente atractiva y dinámica.

## Temas cubiertos
- Transitions (transiciones suaves)
- Animations (animaciones con keyframes)
- 2D Transforms (rotación, escalado, traslación)
- 3D Transforms (perspectiva, rotación 3D)
- Keyframes (definición de animaciones)
- Hover (efectos al pasar el mouse)
- Tooltips (mensajes emergentes al posicionar el cursor)
