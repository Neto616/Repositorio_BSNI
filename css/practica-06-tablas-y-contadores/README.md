# Práctica 6: Tablas y Contadores

##  Objetivo
Diseñar tablas informativas con estilo visual claro y aplicar numeración automática usando contadores de CSS.

## Temas cubiertos
- Tablas (`<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`)
- Contadores (`counter-reset`, `counter-increment`, `content`)
- Paginación básica con enlaces
- Columnas múltiples (`column-count`, `column-gap`, etc.)
