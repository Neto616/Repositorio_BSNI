# Práctica 4: Formulario con Estilo Moderno

## Objetivo:
Aplicar estilos modernos a formularios utilizando CSS avanzado para mejorar la experiencia de usuario.

## Temas cubiertos
- Formularios (`<form>`, `<input>`, `<textarea>`, `<select>`)
- Botones con hover y animaciones
- `placeholder` estilizado y `:focus`
- Variables CSS y uso de `@property`
- Interfaz de usuario (`cursor`, `resize`, `appearance`)
- Tooltips personalizados
- Iconos con imágenes
- Efectos de texto (`text-shadow`, `letter-spacing`)
