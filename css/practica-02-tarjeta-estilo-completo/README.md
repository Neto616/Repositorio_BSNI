# Práctica 2: Tarjeta con Estilo Completo

## Objetivo
Aplicar propiedades visuales avanzadas de CSS para diseñar una tarjeta moderna que combina múltiples elementos estéticos. En esta práctica se busca:

## Temas cubiertos
- Usar **bordes personalizados**, **sombras**, **fondos con imágenes** y **gradientes**.
- Emplear **`border-radius`** para redondear esquinas.
- Aplicar **`box-shadow`** para dar profundidad.
- Usar **`box-sizing`** para un control coherente del diseño.
- Establecer un **layout centrado** con Flexbox.
- Estilizar botones con **hover** y transiciones suaves.
