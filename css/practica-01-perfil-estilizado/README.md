# Práctica 1: Mi Perfil Estilizado

## Objetivo
El propósito de esta práctica es aplicar los fundamentos de CSS en un ejemplo realista, donde se crea una tarjeta de perfil personal. Los objetivos específicos son:

## Temas cubiertos
- Usar **selectores básicos** de CSS (`etiquetas`, `.clases`, `#ids`, `combinadores`).
- Aplicar **colores** personalizados y colores por defecto.
- Elegir y utilizar **tipografías** apropiadas.
- Utilizar **unidades de medida** relativas y absolutas (`px`, `%`, `em`, etc.).
- Definir **márgenes** y **espaciado interno (padding)**.
- Estilizar **enlaces** con estados interactivos (`hover`).
- Usar la declaración `!important` como ejemplo de sobrescritura de estilos.
- Incluir **comentarios CSS** y mostrar la **jerarquía de selectores**.
