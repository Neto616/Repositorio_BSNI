# Práctica 10: Cambio de Estilo Dinámico

## Objetivo
Aplicar conceptos avanzados de CSS para cambiar estilos dinámicamente mediante variables CSS, transiciones y diseño responsivo.

## Temas de CSS usados
- **Variables CSS (`--variables`)**: Definición y uso de variables para controlar colores y estilos en temas claros y oscuros.
- **@property**: Declaración de propiedades personalizadas CSS para poder animar variables (`--bg-color`) y lograr transiciones suaves en cambios de tema.
- **Transiciones CSS (`transition`)**: Aplicación de transiciones en colores y fondos para que los cambios visuales sean fluidos y agradables.
- **Transformaciones 2D (`transform`)**: Uso de escalado y rotación en imágenes con efecto hover para mejorar la interacción visual.
- **Transformaciones 3D (`transform: rotateY`)**: Aplicación de efecto de rotación 3D en videos al hacer hover para dar dinamismo a la página.
- **Media Queries**: Adaptación del diseño para diferentes tamaños de pantalla, ajustando tipografía, márgenes y contenedores para mantener buena legibilidad y usabilidad en dispositivos móviles.
- **Diseño Responsive (RWD)**: Uso conjunto de Media Queries y unidades relativas para que la página se adapte correctamente en distintos dispositivos.
- **Sombra y bordes redondeados**: Uso de `box-shadow` y `border-radius` para mejorar la estética visual de los elementos.
