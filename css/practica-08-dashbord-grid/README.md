# Práctica 8: Dashboard con CSS Grid y Gráficos

## Objetivo
Crear un dashboard funcional y estético utilizando CSS Grid para estructurar las diferentes áreas del panel, aplicar estilos modernos y consistentes en tarjetas, menús y secciones, integrar un gráfico interactivo con Chart.js y asegurar que el diseño sea responsivo y accesible para distintos tamaños de pantalla, todo ello practicando conceptos fundamentales y avanzados de CSS.

## Temas de CSS vistos

- Reset y normalización básica con `* { margin: 0; padding: 0; box-sizing: border-box; }`
- Uso de **CSS Grid Layout** para organizar el diseño principal del dashboard con `grid-template-areas`, `grid-template-columns` y `grid-template-rows`.
- Aplicación de **Flexbox** en componentes específicos (tarjetas, widgets) para distribución y alineación.
- Estilización de elementos interactivos con **hover effects** para mejorar la experiencia de usuario.
- Uso de **propiedades de tipografía**: fuentes sans-serif, tamaños, pesos y colores para mejorar legibilidad.
- Colores, sombras y bordes redondeados para un diseño moderno y profesional.
- Diseño de contenedores con **padding** y **box-shadow** para separación visual y profundidad.
- Estilos para listas y navegación en sidebar, incluyendo efectos visuales para elementos activos y hover.
- Implementación de **media queries** para lograr un diseño responsivo que se adapta a pantallas pequeñas, reordenando el grid y ajustando áreas.
- Integración de un **canvas para gráficos** con estilos complementarios para presentación.
