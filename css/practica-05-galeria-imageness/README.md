# Práctica 5: Galería de Imágenes Estilizada

## Objetivo
Construir una galería de imágenes que demuestre el uso de estilos visuales aplicados con CSS moderno.

## Temas cubiertos
- Responsive Grid Layout
- Transformaciones y transiciones
- Filtros (filters)
- object-fit, aspect-ratio
- Variables CSS
- @media queries
- :hover, :nth-child, ::after, ::before
- Sombras (box-shadow) y bordes redondeados
- Efectos con z-index, position, overflow
- Animaciones básicas (@keyframes)
