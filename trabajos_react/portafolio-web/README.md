## Portfolio Website using React and Bootstrap

# Descripción
Este proyecto es un **sitio web de portafolio profesional** desarrollado con **React** y **Bootstrap**, diseñado para destacar tus habilidades, experiencia, proyectos y proporcionar una manera fácil para que otros se pongan en contacto contigo.

# Tecnologías utilizadas
- ReactJS (Vite o Create React App)
- Bootstrap 5
- JSX
- Diseño Responsivo
- Formulario de contacto
