## Weather Application using ReactJS

# Descripción

Esta es una aplicación interactiva del clima desarrollada con **ReactJS**. Permite a los usuarios obtener información meteorológica en tiempo real de cualquier ciudad del mundo utilizando la API de **OpenWeatherMap**.

Al buscar una ciudad válida, se muestra información como:

- Temperatura
- Condiciones del clima
- Velocidad del viento
- Icono del estado del tiempo

Si el usuario introduce una ciudad incorrecta o no encontrada, se mostrará un mensaje de error amigable.
