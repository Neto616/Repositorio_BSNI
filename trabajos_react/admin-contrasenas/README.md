## Administrador de Contraseñas usando ReactJS

# Descripción
Este proyecto es una **aplicación de gestión de contraseñas** creada con **ReactJS**, que permite a los usuarios **almacenar, editar, eliminar, copiar y visualizar/ocultar contraseñas** de forma segura y eficiente.
Cuenta con una interfaz intuitiva y funcionalidades esenciales para manejar credenciales personales o de trabajo.

# Tecnologías utilizadas

- ReactJS (Componentes de clase)
- CSS
- Renderizado condicional
- Portapapeles (API nativa para copiar)
- Manejo de estado en componentes

# Funcionalidades principales
- **Agregar contraseña:** Guarda una nueva entrada con sitio web, usuario y contraseña.
- **Editar contraseña:** Permite modificar entradas existentes.
- **Eliminar contraseña:** Elimina entradas del listado con alerta de éxito.
- **Copiar contraseña:** Copia la contraseña al portapapeles con un clic.
- **Mostrar/ocultar:** Alterna entre ver la contraseña real o enmascarada (`******`).
- **Formulario dinámico:** El formulario se adapta automáticamente si está en modo edición o creación.
