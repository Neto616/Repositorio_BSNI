## PacMan Game using React

# App
Es un juego web interactivo que replica la jugabilidad del PacMan original con elementos visuales personalizados, control del personaje mediante teclado y lógica programada para el movimiento de los fantasmas, detección de colisiones, puntuación y condiciones de finalización del juego.

# Objetivo
El objetivo de este proyecto es poner en práctica conceptos clave de desarrollo web interactivo utilizando React, incluyendo la manipulación del DOM con hooks, uso de eventos del teclado, control de estados, diseño basado en grid y creación de componentes dinámicos para una aplicación completamente funcional.

# Tecnologías utilizadas
- ReactJS
- HTML5
- CSS3
- JavaScript (ES6+)
- Web Audio API (opcional para efectos de sonido)

# Conceptos utilizados
- Componentes funcionales en React
- Hooks (useState, useEffect, useRef)
- Diseño del laberinto con CSS Grid
- Captura y manejo de eventos del teclado
- Control de colisiones y movimiento dentro del grid
- Lógica de inteligencia artificial básica para fantasmas
- Sistema de puntuación y detección de fin de juego
- Animaciones con CSS o bibliotecas externas
- Separación modular de componentes (PacMan, Ghosts, Maze, ScoreBoard)
