## Aplicación Paint con ReactJS

# App
Esta es una mini aplicación de dibujo que simula el comportamiento básico de MS Paint, permitiendo al usuario pintar sobre un lienzo HTML mediante un pincel personalizable en color, tamaño y opacidad. Ideal como ejercicio práctico para entender cómo trabajar con <canvas> en React.

# Objetivo
El objetivo principal de este proyecto es aprender a integrar y manipular el elemento canvas en una aplicación construida con ReactJS, utilizando componentes funcionales, hooks y control de eventos para simular una herramienta de dibujo interactiva.

# Tecnologías utilizadas
- ReactJS (v18+)
- HTML5 Canvas
- JavaScript (ES6+)
- CSS3

# Conceptos utilizados
- Componentes funcionales de React
- Hooks: useRef, useState, useEffect
- Lógica de eventos del mouse (mousedown, mousemove, mouseup)
- Dibujo con contextos 2D de canvas (getContext("2d"))
- Estado reactivo para pincel (color, grosor, opacidad)
- Separación de componentes y estructura modular
